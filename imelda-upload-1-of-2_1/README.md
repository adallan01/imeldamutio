# Imelda Mutio: radio presenter, MC and event host

Personal-brand and booking website for Imelda Mutio, Nairobi. Built on the same design system as Brian Aseli's site.

- `npm install && npm run dev`: local preview
- `npm run build`: production build into `dist/`
- `npm run check`: links, metadata and unpublished-entry checks

See `HANDOVER.md` for editing and deployment, and `research/facts-to-confirm.md` for what Imelda needs to confirm before launch.
